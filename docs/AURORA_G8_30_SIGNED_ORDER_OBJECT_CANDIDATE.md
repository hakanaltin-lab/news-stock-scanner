# AURORA G8.30 — Signed Order Object Candidate Attestation

This gate verifies **independent human reviewer Ed25519 signatures** for the G8.29 unsigned request concerning the G8.28 non-executable IBKR Order Object candidate. The installed verifier requires fixed, protected policy and public-key paths, compares exact SHA-256 digests across the candidate source, G8.28 review, G8.27 attestation and G8.29 handoff, rejects expired/untrusted artifacts and requires explicit reviewer confirmations.

Trusted reviewer files are **not generated by AURORA**:
- `/etc/aurora/order-object-candidate-review-policy.json`
- `/etc/aurora/order-object-candidate-reviewer-ed25519.pem`
- `/var/lib/aurora/order-object-candidate-review-attestation/latest.json`

Output: `runtime/aurora_g6_order_object_candidate_attestation/latest.json`.

The unit suite simulates the successful signature condition; it is **not evidence that any human reviewed, signed or approved the candidate**. A positive review only advances review status. No Contract/Order creation, API import, connectivity, Paper submission, LIVE execution or real-money order is authorized.
