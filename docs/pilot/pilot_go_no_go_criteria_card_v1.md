# AURORA AI CIO v3.1

# Pilot GO / NO-GO Success Criteria Card v1.0

## Purpose

This document defines the objective evaluation framework for the 90-day AURORA AI CIO Paper Trading Pilot.

The purpose is not only to measure return performance.

The purpose is to validate:

- Investment decision quality
- Risk discipline
- Process consistency
- System reliability

No live capital deployment is allowed before this evaluation is completed.

---

# 1. Pilot Objective

The pilot answers four fundamental questions:

## 1. Can AURORA generate alpha?

Measured against:

- S&P 500
- Nasdaq-100

---

## 2. Can AURORA control risk?

Measured by:

- Drawdown
- Exposure control
- Risk violations

---

## 3. Can AURORA make repeatable decisions?

Measured by:

- Thesis accuracy
- Decision quality
- Catalyst evaluation

---

## 4. Can AURORA operate consistently?

Measured by:

- Journal discipline
- Data integrity
- Process compliance
